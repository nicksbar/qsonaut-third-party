# Contributing

Keep this repository limited to reusable adapters around third-party modem
implementations. Do not move QSONaut or QSONoid application orchestration,
platform lifecycle, UI, radio state, logging, or transmit safety here.

Before opening a pull request, run the commands listed in the PR template.
Any dependency or upstream revision change must update
`THIRD_PARTY_NOTICES.md` and explain the licensing and compatibility impact.
